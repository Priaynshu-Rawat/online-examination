1. What is this project?
The Online Examination System is a web application. Faculty create multiple-choice exams, students take them in a browser, and the system marks everything automatically. An administrator manages accounts. Everything runs on one computer (the server) and anyone on the same network opens it in a browser such as Chrome or Edge.

 1.1 Problem it solves---- 
 Paper exams need printing, supervision, manual checking and manual entry of marks into a register.
 Two teachers of the same subject may unknowingly use the same question. 
 A teacher cannot see which questions the whole class found hard without counting by hand.
 If a student loses internet or the browser crashes, a simple system loses the answers
